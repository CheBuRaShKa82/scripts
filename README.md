# 🛡️ VPS Setup Scripts

Набор Bash-скриптов для быстрой первоначальной настройки безопасности и рабочего окружения на **Ubuntu / Debian VPS** с `systemd`:

- 🔐 базовое усиление безопасности сервера (`secure-vps.sh`);
- 🐳 автоматическая установка Docker Engine и Docker Compose из официального репозитория Docker (`install-docker.sh`).

---

## 📦 Содержимое репозитория

| Скрипт | Назначение |
|---|---|
| `secure-vps.sh` | Интерактивная базовая защита VPS: отдельный пользователь, SSH, UFW, Fail2Ban, sysctl, Telegram и двухэтапная проверка с автооткатом |
| `install-docker.sh` | Автоматическая установка Docker Engine, Buildx и Compose Plugin для Ubuntu / Debian |

---

# 🔐 secure-vps.sh

Интерактивный скрипт для базовой защиты нового VPS с защитой от потери доступа (двухэтапная проверка подключения и автооткат при ошибке).

## Что настраивает скрипт

- **Администратор**: создание отдельного пользователя в группе `sudo` с обязательным паролем (не менее 12 символов).
- **SSH**: запрет входа под `root`, ограничение доступа через `AllowUsers`, сменяемый порт, вход только по SSH-ключу (рекомендуется) или паролю.
- **Firewall (UFW)**: закрытие всех входящих соединений по умолчанию; при сбросе UFW остаётся разрешён только выбранный SSH-порт, а при отказе существующие правила сохраняются и добавляется новый SSH-порт.
- **Fail2Ban**: защита SSH от подбора паролей с добавлением вашего IP в белый список и постепенным увеличением времени блокировки.
- **Telegram**: отправка оповещений об успешном SSH-входе и блокировках IP через Fail2Ban.
- **Система**: применение базовых защитных параметров ядра `sysctl` и опциональная активация автоматических обновлений безопасности (`unattended-upgrades`).

---

## ⚠️ Что подготовить перед запуском

- **Telegram-бот**: создайте бота в [@BotFather](https://t.me/BotFather) и узнайте числовой `TG_CHAT_ID` (например, через [@userinfobot](https://t.me/userinfobot)). Токен и ID чата обязательны для запуска мастера.
- **SSH-ключ**: подготовьте ваш публичный ключ при выборе входа по ключу (скрипт также может импортировать подходящие ключи из `/root/.ssh/authorized_keys`).
- **Панель хостинга**: если у VPS-провайдера включен внешний Firewall / Security Group, заранее разрешите выбранный SSH-порт.
- **Сессия терминала**: держите текущую сессию открытой до завершения всех проверок.

---

## 🚀 Запуск и порядок работы мастера

> [!IMPORTANT]
> `secure-vps.sh` необходимо запускать от `root` или через `sudo` в интерактивном терминале.
> Запуск через `curl ... | bash`, CI/CD или stdin без TTY не поддерживается.

```bash
git clone https://github.com/CheBuRaShKa82/scripts.git
cd scripts
chmod +x secure-vps.sh install-docker.sh
sudo ./secure-vps.sh
```

### Порядок работы мастера:

1. **Сбор параметров:** скрипт последовательно запрашивает токен Telegram, `TG_CHAT_ID`, имя администратора, способ SSH-аутентификации, пароль пользователя для `sudo` (не менее 12 символов), порт SSH, IP для белого списка Fail2Ban, автообновления и режим сброса правил UFW.
2. **Подтверждение:** выводится сводная таблица всех указанных параметров, после чего требуется ввести `YES` для продолжения.
3. **Тест Telegram:** скрипт проверяет возможность отправки тестового сообщения. Если Telegram API временно недоступен, скрипт выведет предупреждение и продолжит настройку.
4. **Применение SSH и первая проверка:** создаётся пользователь, настраиваются SSH, PAM и Fail2Ban, после чего скрипт ожидает проверки подключения во втором окне терминала (таймаут 5 минут).
5. **Настройка UFW и вторая проверка:** настраивается firewall и выполняется повторная проверка SSH-доступа во избежание блокировки (таймаут 5 минут).

## 📲 Telegram

Для запуска необходимо указать:

- `Telegram Bot Token`;
- числовой `TG_CHAT_ID`.

Перед применением основных изменений скрипт проверяет возможность отправки тестового сообщения.

Если Telegram API временно недоступен, скрипт выведет предупреждение и продолжит настройку.

После установки Telegram используется для уведомлений:

- об успешном SSH-входе;
- о блокировке IP через Fail2Ban.

---

## 🧯 Защита от потери доступа (Rollback)

В процессе настройки предусмотрены две обязательные проверки SSH с таймаутом 5 минут.

1. **После изменения SSH:** необходимо подключиться в новом окне по новому порту, проверить `sudo` и Telegram-уведомление.
2. **После настройки UFW:** необходимо повторно проверить SSH-доступ через firewall.

> [!IMPORTANT]
> Если первая проверка не пройдена, скрипт выполняет полный откат внесённых изменений, включая SSH-конфигурацию и созданного пользователя.
>
> После успешной первой проверки новый пользователь и SSH-настройки считаются рабочими. Если проблема возникает на финальном этапе настройки UFW, скрипт откатывает настройки firewall, сохраняя рабочий SSH-доступ.

# 🐳 install-docker.sh

Автоматический установщик Docker Engine, Buildx и Docker Compose Plugin для **Ubuntu** и **Debian**.

Скрипт определяет дистрибутив через `/etc/os-release`, проверяет архитектуру и подключает официальный репозиторий Docker.

## Что устанавливается

- `docker-ce`
- `docker-ce-cli`
- `containerd.io`
- `docker-buildx-plugin`
- `docker-compose-plugin`

---

## 🚀 Установка Docker

```bash
chmod +x install-docker.sh
sudo ./install-docker.sh
```

Скрипт выполняет следующие шаги:

1. Удаляет конфликтующие пакеты (`docker.io`, `containerd`, `podman-docker` и др.).
2. Устанавливает зависимости `ca-certificates` и `curl`.
3. Добавляет официальный GPG-ключ Docker и настраивает репозиторий в `/etc/apt/sources.list.d/docker.sources`.
4. Устанавливает официальный Docker Engine, Buildx и Compose Plugin.
5. Включает и запускает службу Docker через `systemd`.
6. При интерактивном запуске через `sudo` предлагает добавить пользователя, от имени которого был вызван `sudo`, в группу `docker` для запуска без `sudo`.

---

## ⚠️ Docker и UFW

> [!WARNING]
> Docker по умолчанию управляет цепочками `iptables` напрямую в обход правил UFW. Опубликованный контейнером порт (например, `-p 8080:8080`) может оказаться доступен извне даже при политике `ufw default deny incoming`.

- Для локальных сервисов публикуйте порты только на интерфейсе loopback: `127.0.0.1:8080:8080`.
- Для централизованного ограничения доступа извне используйте цепочку `DOCKER-USER` в `iptables`.

## 🖥 Поддерживаемые системы

Скрипты рассчитаны на:

- **Ubuntu** и **Debian** с `systemd`;
- пакетный менеджер `apt` и OpenSSH.

Скрипты **не предназначены** для систем семейств RHEL (CentOS, Rocky Linux, AlmaLinux), Alpine Linux или Arch Linux.

## 📋 Рекомендуемый порядок настройки нового сервера

1. **Базовая защита сервера:**
   ```bash
   sudo ./secure-vps.sh
   ```
2. **Переподключение под новым администратором:**
   ```bash
   ssh -p PORT USERNAME@SERVER_IP
   ```
3. **Установка Docker:**
   ```bash
   sudo ./install-docker.sh
   ```
4. **Открытие портов веб-сервера (при необходимости):**
   ```bash
   sudo ufw allow 80/tcp
   sudo ufw allow 443/tcp
   ```

## 🔎 Полезные команды

| Задача | Команда |
|---|---|
| Проверка статуса UFW | `sudo ufw status verbose` |
| Список правил UFW с номерами | `sudo ufw status numbered` |
| Статус защиты Fail2Ban | `sudo fail2ban-client status sshd` |
| Проверка эффективного конфига SSH | `sudo sshd -T` |
| Проверка работы Docker | `sudo docker run --rm hello-world` |
| Список активных контейнеров | `sudo docker ps` |
| Статус службы Docker | `sudo systemctl status docker` |
| Логи службы SSH | `sudo journalctl -u ssh` |
